# Package index

## Mining genbank

Functions to mine genbank

- [`gene.sampling.retrieve()`](https://ropensci.github.io/phruta/reference/gene.sampling.retrieve.md)
  : Retrieve the distribution of genes for given organism in genbank
- [`acc.table.retrieve()`](https://ropensci.github.io/phruta/reference/acc.table.retrieve.md)
  : Retrieve accession numbers and titles for a given combination of
  species and genes in genbank
- [`sq.retrieve.direct()`](https://ropensci.github.io/phruta/reference/sq.retrieve.direct.md)
  : Retrieve sequences from genbank
- [`sq.retrieve.indirect()`](https://ropensci.github.io/phruta/reference/sq.retrieve.indirect.md)
  : Retrieve sequences from genbank based on a dataset of accession
  numbers

## Pre-processing sequences

Functions for pre-processing sequences.

- [`sq.add()`](https://ropensci.github.io/phruta/reference/sq.add.md) :
  Add local sequences to previously downloaded sequences
- [`sq.curate()`](https://ropensci.github.io/phruta/reference/sq.curate.md)
  : Curate sequences from genbank
- [`sq.aln()`](https://ropensci.github.io/phruta/reference/sq.aln.md) :
  Align sequences

## Inferring and exploring phylogenies

Functions for inferring and exploring phylogenetic trees

- [`tree.constraint()`](https://ropensci.github.io/phruta/reference/tree.constraint.md)
  : Tree inference under RAxML
- [`tree.dating()`](https://ropensci.github.io/phruta/reference/tree.dating.md)
  : Tree dating under treePL or
- [`tree.raxml()`](https://ropensci.github.io/phruta/reference/tree.raxml.md)
  : Tree inference under RAxML
- [`tree.roguetaxa()`](https://ropensci.github.io/phruta/reference/tree.roguetaxa.md)
  : RogueNaRok within phruta
- [`sq.partitionfinderv1()`](https://ropensci.github.io/phruta/reference/sq.partitionfinderv1.md)
  : Run Partitionfinder v.1
